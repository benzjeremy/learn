🎓 3. Curricula & Kernfächer 3. Curricula & Core Subjects

Die Curricula orientieren sich an der staatlichen Ausbildungsordnung für Fachinformatiker (Anwendungsentwicklung & Systemintegration). Jedes Fach umfasst strukturierte Theorie, interaktive Quizzes, Inline-Code-Aufgaben, Compiler-Bugfixes und eine abschließende Fachprüfung: The curricula align with vocational standards for software engineers and systems specialists. Each course includes structured theory, interactive quizzes, inline code exercises, compiler bugfixes, and a final subject exam:

  • Go (Golang): 8 vollständige Kapitel von Syntax, Kontrollfluss, Slices/Pointers, Structs/Interfaces über Concurrency/Channels bis Tooling & HTTP-Server.
  • Cybersecurity: OWASP Top 10, Zero-Trust, symmetrische/asymmetrische Kryptografie (AES-256-GCM, PBKDF2), CSRF & DNS-Rebinding Schutz.
  • SQL & Datenbanken: Relationale Modellierung (1:1, 1:n, n:m), DDL/DML, Normalisierung (1NF–3NF), Indizes, ACID-Transaktionen.
  • C# & .NET: OOP, Delegates/Events, LINQ, Garbage Collection, async/await und CLR-Internals.
  • Astro & Modern Web: Island Architecture, Zero-JS by Default, Content Collections, Static Site Generation (SSG) & SSR.
  • Python: Datenstrukturen, List Comprehensions, Decorator, Generatoren, OOP und idiomatische CLI-Tools.
  • HTML5 & CSS3: Semantisches Web, Flexbox, CSS Grid, Container Queries, responsive Typografie und Barrierefreiheit (WCAG AAA).
  • JavaScript: ESNext, Event Loop, Promises, Closures, DOM-Manipulation, Strict Mode und Prototypal Inheritance.
  • PHP: Modernes PHP 8+, Type Hinting, Attributes, PSR-Standards, Composer, PDO und Prepared Statements.

🛠️ 4. Interaktives Compiler-Labor 4. Interactive Compiler Lab

Damit Lernende nicht nur passive Multiple-Choice-Fragen beantworten, sondern echte Code-Schreib-Kompetenz entwickeln, enthält learn ein interaktives Compiler-Labor direkt im Browser: To ensure learners acquire real code-writing competence rather than just clicking through multiple-choice questions, learn includes an in-browser compiler lab: 

// Beispiel aus Go Kapitel 1 (Abschnitt 5: Compiler-Labor)
package main

import "fmt"

func main() {
    // BUG: fmt.Printlln existiert nicht!
    fmt.Println("Hallo Welt aus Go!")
}
⚠️ Realistische Terminal-Ausgaben Realistic Terminal Diagnostics

Wird der Fehler nicht behoben, meldet das Terminal Exit Code 1 mit exakter Zeilenangabe: ./main.go:6:5: undefined: fmt.Printlln (did you mean fmt.Println?). Erst bei fehlerfreier Korrektur meldet das Terminal Exit Code 0: Compilation & Run Successful. If uncorrected, the terminal reports Exit Code 1 with exact line coordinates: ./main.go:6:5: undefined: fmt.Printlln (did you mean fmt.Println?). Only upon correct syntax does the terminal emit Exit Code 0: Compilation & Run Successful.

💡 6. Distraktor-Didaktik ohne Lösungs-Spoilen 6. Distractor Didactics (Zero Solution-Spoiling)

In traditionellen Apps führt eine falsche Antwort oft dazu, dass sofort die richtige Lösung eingeblendet wird. Dadurch lernt der Nutzer jedoch nichts, sondern merkt sich nur die Position der richtigen Option. Traditional learning apps often immediately reveal the correct solution upon a wrong choice, preventing true retention.

🧠 Wie learn Feedback liefert How learn Delivers Feedback

Wählt der Nutzer beispielsweise := statt des Channel-Operators <-, blendet das System ein: „Didaktischer Hinweis: := ist der Kurzdeklarations-Operator für Variablen (z. B. x := 42) und hat keinen Bezug zu Goroutine-Channels.“ Die Optionen bleiben aktiv, und der Nutzer erarbeitet sich die Lösung selbst. If a user selects := instead of the channel operator <-, the app explains: "Didactic Note: := is the short variable declaration operator (e.g. x := 42) and is not used for goroutine channels." The options remain interactive, encouraging self-guided discovery.

🔔 7. Lokales Erinnerungssystem 7. Local Reminder System

learn respektiert die Privatsphäre des Nutzers. Daher gibt es keinen zentralen Push-Server und keine Cloud-Tracker. Das Benachrichtigungssystem läuft zu 100% lokal auf dem Endgerät: learn respects privacy. There is no central push notification server or cloud tracker. Reminders run 100% locally on the device:

  • Tägliche Erinnerung: Frei wählbare Uhrzeit (z. B. 18:00 Uhr) zur Etablierung einer täglichen Lern-Gewohnheit.
  • Höflicher Inaktivitäts-Nudge: Erkennt die App nach 3–5 Tagen keine Aktivität, erinnert sie dezent daran, wieder ein kurzes Kapitel zu absolvieren.
  • Web Notifications API: Im Browser über native HTML5 Notifications nach einmaliger Erlaubnis.
  • Android AlarmManager: Unter Android über energiesparende Betriebssystem-Alarme ohne Hintergrund-Batterieverbrauch.

❓ 10. Häufige Fragen (FAQ) 10. Frequently Asked Questions (FAQ)

Werden meine Daten in der Cloud gespeichert?Is my progress stored in the cloud?

Nein. Alle Fortschritte, XP-Punkte, Streaks und Prüfungsergebnisse werden zu 100% lokal gespeichert (SQLite WAL auf Desktop/Android, isolierte IndexedDB im Web-Browser). Null Cloud-Speicher, null Tracking. No. All progress, XP, streaks, and exam results are stored 100% locally (SQLite WAL on desktop/Android, isolated IndexedDB in web browsers). Zero cloud storage, zero telemetry.

Kostet die App oder ein Zertifikat Geld?Does the app or certification cost money?

Nein. Alle Kurse, Übungen, Compiler-Prüfungen und Notenbescheinigungen sind unter der GNU General Public License v3.0 bedingungslos kostenlos und open source. No. All courses, exercises, compiler challenges, and exam report cards are unconditionally free and open source under GNU General Public License v3.0.
